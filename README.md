# Evo

> Public source preview: see [PUBLICATION.md](PUBLICATION.md) for actual checks, known failures and runtime limits.

## Описание

Игровой прототип про эволюцию существ, где игрок выбирает стартовый вид и наблюдает за борьбой за пищу и выживание. Проект построен как лёгкая симуляция с элементами выбора расы и динамики популяции.

## Что реализовано

- несколько типов существ с разными характеристиками;
- генерация еды и простого мира;
- выбор стартового вида через меню;
- визуализация происходящего в `pygame`;
- цикл обновления популяции в реальном времени.

## Стек

- Python
- pygame

## Запуск

```bash
pip install pygame
python main.py
```
